# grok-coding-test

ミューズ → GitHub → Grok の経路で、コーディングの一部を Grok に任せる試験用リポジトリです。

## 進め方

1. ミューズが `grok-tasks/` にタスク仕様を置いて push する
2. Grok は GitHub コネクタ経由でタスクを読み、作業ブランチで実装して PR を作る
3. ミューズが PR を読み戻し、差分確認と動作確認をしてからマージ可否を判断する

## ルール

- Grok の作業ブランチはタスクごとに `grok/G-xxx` とし、main へ直接 push しない（PR 経由のみ）
- 秘密情報・個人データは置かない
- 外部通信を発生させるコード（CDN、フォント、解析など）は入れない
