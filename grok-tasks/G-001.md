# G-001: カウンター画面を作る

## 目的

Grok がこのタスクファイルを読み、ブランチ作成・ファイル作成・PR 作成までできるかを検証する試験タスク。

## 作業ブランチ

`grok/G-001`（main から切ること。main へ直接 push しないこと）

## 作るもの

リポジトリ直下に `counter.html` を 1 ファイルだけ新規作成する。

要件:

- 単一 HTML ファイルで完結する。CSS と JavaScript はファイル内に書く
- 外部ファイル、CDN、フレームワークは使わない
- タイトルは「カウンター」
- 画面中央に現在のカウントを大きく表示する（初期値は 0）
- ボタンは 3 つ:「+1」「-1」「リセット」
  - 「+1」: カウントを 1 増やす
  - 「-1」: カウントを 1 減らす。ただし 0 未満にはしない
  - 「リセット」: カウントを 0 に戻す
- ファイルをブラウザで直接開いて動作すること

## 変更してよいファイル

- `counter.html`（新規作成）のみ

## 変更禁止

- `README.md`、`AGENTS.md`、`grok-tasks/` 配下のすべて

## 完了条件

- ブランチ `grok/G-001` に `counter.html` が追加されている
- main 向けの PR が作られている（タイトルに `G-001` を含める）
- PR の説明に、実装した内容の要約を書く
